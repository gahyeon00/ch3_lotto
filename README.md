🎱 Streamlit Lotto Number Generator
Streamlit을 활용하여 만든 직관적이고 예쁜 로또 번호 생성기 웹 애플리케이션입니다. 실제 로또 공 색상 규칙을 적용하여 시각적인 재미를 더했습니다.

🚀 주요 기능
로또 번호 생성: 1부터 45 사이의 숫자 중 중복 없는 6개의 번호를 랜덤 추출합니다.
세트 누적 관리: '번호 생성' 버튼을 계속 누르면 최대 5개 세트까지 화면에 누적되어 표시됩니다.
실제 로또 공 색상 적용:
1 ~ 10: 노란색
11 ~ 20: 파란색
21 ~ 30: 빨간색
31 ~ 40: 회색
41 ~ 45: 초록색
🛠️ 설치 및 실행 방법
1. 사전 요구사항
Python 3.8 이상이 설치되어 있어야 합니다.
2. 패키지 설치
터미널(Terminal 또는 CMD)을 열고 프로젝트 폴더 경로에서 아래 명령어를 입력하여 필요한 라이브러리를 설치합니다.

pip install -r requirements.txt
3. 앱 실행
아래 명령어를 실행하면 자동으로 웹 브라우저가 열리며 로또 번호 생성기 앱이 실행됩니다.

streamlit run app.py
